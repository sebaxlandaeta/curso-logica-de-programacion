# Nivel 1: Fundamentos y Programación Secuencial

Nivel 1 del curso de lógica de programación en Python, enfocadas en la asignación de variables, operaciones aritméticas, uso de entradas/salidas y generación de números aleatorios.

---

## 📋 Resumen de Desafíos

### Desafío 1: Cálculo de Sueldos de Vendedores
**Objetivo:** Calcular los ingresos totales de un vendedor mediante variables estáticas y aleatorias.

**Requerimientos principales:**
1. Asignar nombre y salario base fijo.
2. Generar horas trabajadas (5 a 40) y tarifa por hora (20 a 50) usando la librería `random`.
3. Calcular el monto por horas trabajadas y el salario total (salario base + monto extra).
4. Mostrar en pantalla el desglose completo de la información del vendedor.

---

### Desafío 2: Sistema de Alquiler de Vehículos
**Objetivo:** Automatizar el cálculo de costos para el alquiler de vehículos aplicando lógica secuencial.

**Requerimientos principales:**
1. Documentar mediante comentarios el análisis de entradas y salidas del problema.
2. Solicitar al usuario el modelo del vehículo y la cantidad de días (`int`).
3. Generar un costo diario aleatorio entre 25$y 50$.
4. Calcular el monto total del alquiler y la inicial obligatoria del 35%.
5. Imprimir un recibo detallado con los datos de la transacción.
